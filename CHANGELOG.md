# Changelog

All notable changes to MountainPilot are recorded here.

## [1.0.0] - 2026-10-15

### Added

- Directed road graph with Dijkstra and A* planners.
- EV energy estimate with fast, eco, and comfort profiles.
- Behavior FSM, PID, Pure Pursuit, and offline kinematic simulation.
- Constrained bilingual cockpit route-preference parser.
- Three-scenario JSON/CSV benchmark and 30 milestone devlogs.

### Verified

- Standard-library unit and regression suite on the local Python 3.12 environment.
- End-to-end Chinese eco-route demo and repeatable benchmark export.

## [0.1.0] - 2026-08-05

### Added

- Initial Python project structure.
- CARLA client connection probe with explicit dependency and server failure states.
- Standard-library unit tests for the probe.
- GitHub Actions continuous-integration workflow.
- Day 01 development log and 30-day roadmap.
